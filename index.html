About

Principal Architect at NTT DATA, Microsoft MVP and MCT. I help teams turn emerging Microsoft technologies into secure, scalable solutions.

Holger is a Principal Architect and Microsoft MVP specializing in agentic AI, autonomous systems, and the Microsoft Power Platform — with a deep focus on Copilot Studio and Azure AI Services. He designs and implements agentic AI systems that support autonomous decision-making and intelligent process automation in enterprise environments, building secure, scalable, and well-governed solutions.

His work spans enterprise AI, Microsoft Copilot Studio, Power Platform, Dynamics 365, and intelligent automation. He advises organizations on the design and implementation of AI-powered business solutions that improve operational efficiency, enhance customer engagement, and deliver measurable business outcomes.

Copilot Studio

Building Agents with Copilot Studio: From Orchestration to Customer Service

Choose the right harness for your workload, connect enterprise knowledge and tools, and design event-driven workflows with clear human checkpoints. Explore customer-facing chat and voice scenarios, with the Customer Conversation harness explicitly covered as preview.

Agent evaluation

Rethinking Agent Testing: Repeatable Evaluations in Copilot Studio

Build representative test conversations, score response quality, and detect regressions before publishing. Demonstrate the native Evaluate tab (preview), explain its scoring, signed-in user context, and credit usage, and compare it with batch testing and rubrics in the separately maintained Copilot Agent Kit.

Dynamics 365

From Inbox to Resolution: Copilot Studio & Dynamics 365

Design a composed service solution that connects email-triggered workflows, business actions, and Dynamics 365 case management. Extend it to chat and voice with human escalation, distinguishing the Customer Conversation harness (preview) from channel-specific capabilities and deployment requirements.

Multi-agent systems

Multi-Agent Patterns in Copilot Studio: Composition, Tools & Handoffs

Decide when a single agent is enough, when to use child agents, and when separate ownership calls for connected agents. Distinguish A2A task delegation from MCP tool access, and design context handoffs, identity boundaries, and evaluations. Preview and early-release integrations are identified rather than presented as generally available.

Workshop

Agent in a Day: Build, Test & Publish

A hands-on introduction aligned with Microsoft's current Agent in a Day learning path: declarative agents in Microsoft 365 Copilot Chat and custom engine agents in Copilot Studio. Explore knowledge, tools, agent flows, generative orchestration, and autonomous functionality, with practical testing and publishing steps.

Microsoft Foundry

Agentic AI with Microsoft Foundry: From Prototype to Production

Design an agent solution with Microsoft Foundry Agent Service and choose an appropriate runtime and tool integration strategy. Cover Microsoft Entra identity, access controls, tracing, evaluations, and operational monitoring, separating production architecture from preview capabilities.

Reviewed against Microsoft documentation on 29 October 2026. Availability can vary by harness, environment, region, and release cycle. The former Copilot Studio Kit is now named Copilot Agent Kit; its repository still documents testing capabilities, rather than a blanket retirement.
